# Домашняя работа 21.2: Основы верстки

---

## 📌 Описание проекта
Данный проект представляет собой простое веб-приложение, написанное на чистом Python (без использования фреймворков) и HTML/CSS с применением Bootstrap. Приложение демонстрирует понимание основ работы HTTP-протокола, маршрутизации запросов и рендеринга HTML-страниц.

## ✨ Реализованный функционал
- [x] **Верстка на Bootstrap 5**: Адаптивный дизайн с боковой панелью навигации, карточками товаров и формами.
- [x] **Обработка GET-запросов**: Маршрутизация по страницам (`/`, `/category`, `/orders`, `/contacts`, `/profile`).
- [x] **Обработка POST-запросов**: Прием данных из формы на странице "Контакты" и вывод их в консоль сервера.
- [x] **Безопасная работа с файлами**: Чтение HTML-шаблонов осуществляется через контекстный менеджер `with open()`.
- [x] **Кастомная страница 404**: Корректная обработка несуществующих маршрутов с отдачей HTTP-статуса 404.
- [x] **Корректное завершение работы**: Реализован механизм graceful shutdown сервера при переходе на страницу `/logout` (с закрытием вкладки браузера через JS).
- [x] **Типизация и документация**: Код снабжен аннотациями типов (type hints) и подробными docstring-комментариями.

## 🚀 Как запустить проект
#### 1. Клонируйте репозиторий (если еще не сделали этого):
```bash
   git clone https://github.com/DiamondDim/homework_21_2.git
   cd homework_21_2
```
#### 2. Создайте и активируйте виртуальное окружение:
```bash
   poetry install
```
#### 3. Запустите сервер:
```bash
   poetry run python server.py
```
#### 4. Откройте браузер и перейдите по адресу:
👉 [http://localhost:8080](http://localhost:8080)

## 🔄 Механизм выхода из системы
#### При переходе на страницу /logout происходит:

- Отправка HTML-страницы с уведомлением об успешном выходе
- Запуск отдельного потока для корректной остановки сервера
- Автоматическое закрытие браузера через JavaScript
- Корректное завершение работы серверного процесса
